# Tailwind Visual Edit

Color-coded Tailwind CSS class highlighting and visual editing panel for VS Code.

## Features

- **Color-coded classes**: Each Tailwind class in your `className` is colored by category (Layout, Spacing, Typography, Colors, etc.)
- **Visual editing panel**: Edit Tailwind classes visually from the sidebar (spacing, typography, colors, effects)
- **Hover info**: Hover over a class to see its category

## Supported languages

- TypeScript React (`.tsx`)
- JavaScript React (`.jsx`)
- HTML
- Vue
- Svelte
- Astro
- PHP

## Usage

1. Open a file containing Tailwind classes
2. Classes in `className` attributes are automatically color-coded by category
3. Click the **Tailwind Visual Edit** icon in the activity bar to open the visual editor
4. Place your cursor inside a JSX/HTML element to edit its classes visually

## Category colors

| Category       | Description                          |
|----------------|--------------------------------------|
| Layout         | flex, grid, block, hidden, etc.      |
| Spacing        | p-, m-, gap, space, etc.             |
| Sizing         | w-, h-, min-w, max-h, etc.          |
| Typography     | text-, font-, leading, etc.          |
| Colors         | bg-, text-color, border-color, etc.  |
| Borders        | border, rounded, ring, etc.          |
| Effects        | shadow, opacity, blur, etc.          |
| Interactivity  | cursor, select, scroll, etc.         |

## Commands

- **Tailwind Visual Edit: Toggle Class Highlighting** - Enable/disable class coloring
